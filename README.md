## 📌 Sobre o Projeto

Aplicação desenvolvida em **Node.js + TypeScript** para buscar usuários do GitHub utilizando a API oficial e salvar os dados localmente em um arquivo JSON.

Projeto criado com foco em:

* boas práticas
* organização de código
* tratamento de erros
* aprendizado de TypeScript
* portfólio QA/Automação

---

# ✨ Funcionalidades

✅ Buscar usuários do GitHub
✅ Validar nome de usuário
✅ Exibir informações do perfil
✅ Salvar usuários em arquivo JSON
✅ Evitar usuários duplicados
✅ Tratamento de erros
✅ Estrutura organizada em camadas

---

# 🛠️ Tecnologias Utilizadas

* ⚡ Node.js
* 🔷 TypeScript
* 🐙 GitHub REST API
* 📂 File System (`fs`)
* 💻 readline/promises
* 🌐 Git/GitHub

# ▶️ Como Executar

## 1️⃣ Clonar o repositório

```bash
git clone https://github.com/carioca1965/projeto-sctec2.git
```

---

## 2️⃣ Entrar na pasta do projeto

```bash
cd projeto-sctec2
```

---

## 3️⃣ Instalar dependências

```bash
npm install
```

---

## 4️⃣ Executar o projeto

```bash
npm run dev
```
